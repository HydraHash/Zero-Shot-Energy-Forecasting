# TimesFM 2.5, 3.0 Zero-Shot Forecasting Implementation
This folder contains implementations for the TimesFM 2.5 and TimesFM3.0 models. 
Since both models were published by the same organization, both models are implemented in this shared folder.
Based on this, the implementations are very similar.

TimesFM 2.5 Implementation: zs_forecast.py
TimesFM 3.0 Implementation: zs_forecast_v3.py

## Virtual Environment and Python Version
Python-Version used: Python 3.13.12
All required packages are contained in requirements.txt file.
