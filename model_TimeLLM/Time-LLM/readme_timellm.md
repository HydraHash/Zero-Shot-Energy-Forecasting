# TimeLLM Zero-Shot Forecasting Implementation
This folder contains implementations for the TimeLLM model. 
The Implementation was adjusted to implement a true zero-shot paradigm instead of having in-domain training.

File name: run_timellm_tsz.py

## Virtual Environment and Python Version
Python-Version used: Python 3.13.12
All required packages are contained in requirements.txt file.
