# Kairos 10m, 23m 50m Zero-Shot Forecasting Implementation
This folder contains implementations for the three Kairos models. 
Since all models were published by the same organization, all three models are implemented in this folder and even the same implementation file.


File Name: zs_forecast_kairos.py
This implementation runs all three model parameters sizes in one pipeline.

## Virtual Environment and Python Version
Python-Version used: Python 3.13.12
All required packages are contained in requirements.txt file.
