# Statistical Baselines Forecasting Implementation
This folder contains implementations for the statistical baselines Seasonal Naive and Historic Average. 
Both algorithms are implemented in a single file.

File name: vectorized_predictions.py

## Virtual Environment and Python Version
Python-Version used: Python 3.13.12
All required packages are contained in requirements.txt file.
