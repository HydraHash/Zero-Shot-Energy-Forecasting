# Moirai 1.9, 1.1, 2.0 Zero-Shot Forecasting Implementation
This folder contains implementations for the three Moirai models. 
Since all three models were published by the same organization, all models are implemented in a single file.


File Name: zs_forecast.py

## Virtual Environment and Python Version

All required packages are contained in requirements.txt file.
